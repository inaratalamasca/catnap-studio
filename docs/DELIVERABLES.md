# Downloads, screenshots and host decisions

## Current public package choices

Use the [0.6.7 preview release](https://github.com/inaratalamasca/catnap-theatre/releases/tag/v0.6.7-preview) to choose:

- **Theatre + Inbox** — presentation plus optional LP/AP inbox/playlist creation and managed Suno/YouTube show controls.
- **Inbox-only** — playlist creation without Theatre playback, broadcasting or an advanced hosting bot.

Both are development previews with included setup instructions and noncommercial/license notices. No LLM is required for deterministic managed-queue operations. Optional Suno authorization/playlist creation uses the host's own account and desktop companion setup. Keep private pairing, publish keys and inbox records out of packages and screenshots.

The [older 0.5.0 presentation-only release](https://github.com/inaratalamasca/catnap-theatre/releases/tag/v0.5.0) remains available. The **0.5.0 Chrome Web Store beta is pending review**; no published Store listing is claimed. Private advanced Theatre 0.6.7 / Host Controls 0.4.8 source and paired downloads are not public deliverables.

The 0.6.2 own-profile authorization, playlist creation and clean Suno/HQ audio reports are useful smoke evidence. The 0.6.3 trial missed the native Play control; 0.6.4 found the row and quiet Load worked, but Play timed out waiting for the selected song. The 0.6.5 host retry reported “Target matched, audio not found”. Version 0.6.6 corrected active-music versus silent-helper selection; the host confirmed the standalone sequence Play song 1 → held ending → Load Next paused → Play song 2. The trial exposed missing managed lyrics; the 0.6.7 lyrics-details correction still needs its real host check. Mixed-source, AP, advanced live integration and Discord/HQ checks remain separate. Label screenshots from isolated fixtures as fixtures; do not present them as real-show acceptance.

## Decisions already made

Public Theatre, overview/website and inbox guide; private advanced-hosting/simulcast source during the pilot; PolyForm Noncommercial terms with separate commercial permission; approved AIU branding inclusion with separate branding rights; Chrome/Brave first and Firefox separate; host-owned Suno authorization; deterministic queue operations without an LLM; managed external entries without required Suno placeholders; prefer a proven OBS adapter before a new Studio encoder.
