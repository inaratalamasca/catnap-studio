Install Community

  1. Download the ZIP above and extract it to a folder you’ll keep.
  2. Open Extensions. Type chrome://extensions in Chrome or brave://extensions in Brave.
  3. Turn on Developer mode, choose Load unpacked, then select the extension folder inside the extracted ZIP. That folder contains manifest.json.
Chrome Web Store install

When Community has a public listing, the link will be here. There you’ll choose Add to Chrome and confirm. Use the direct ZIP for early access today.

Put on your first show

  1. Open a Suno playlist in the same browser profile and press Suno’s Play.
  2. Click Catnap Theatre on the page, then open Controls.
  3. Pick a layout. Try Artwork + lyrics, Playlist + artwork + lyrics, or Artwork focus.
  4. Try Visuals & quick banners for a picture, GIF, muted clip, or message. The optional background bars react when the browser has a usable audio feed.

Between songs and shows

Open the lounge from Controls for a waiting, pre-show or after-show screen. You can play AIU Radio, type the next show time, or save a Suno playlist link.

What do I need?

Chrome or Brave on a computer, and a Suno playlist you can play. Community needs no GPT or AI account, Suno MCP connection, desktop helper, inbox, or Discord setup.
