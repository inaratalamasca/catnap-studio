# Private material and issue reports

Report reproducible failures without tokens, connection files, user messages or browser sessions. Replace private IDs and hosts with clearly labeled examples. If a secret enters Git history, removing it in a later commit is insufficient; rotate it and handle history cleanup deliberately.

The standalone product should require only Suno-scoped presentation access and local settings. The hosting product has a larger trust boundary and separate private pairing. Keep bot secrets server-side. Never broaden allowed destinations or reuse an expired watcher lease silently.

This initial repository contains source/documentation, not a hosted collection service. Before any public or Store release, verify actual data flows against the final privacy declaration and run the product's acceptance checklist.
